\# StudyPal 📚



StudyPal is a personalized study planning web application built with Flask and SQLite. It helps students create study plans based on their subjects, exam date, available study hours, and difficulty level.



\## ✨ Features



\- 📝 Create personalized study plans

\- 📅 Plan studies based on exam date and available time

\- 📚 Organize tasks by subject

\- 🎯 Task types such as learning, practice, revision, and testing

\- ✅ Track daily task completion

\- ⏱️ Track actual study time using a study timer

\- 💭 Update task confidence levels

\- 📊 View study progress and analytics

\- 🔥 Track study streaks

\- 🔄 Adaptive study plan adjustment based on study progress

\- 📋 View previously generated study plans

\- 👤 User registration and login



\## 🛠️ Technologies Used



\- Python

\- Flask

\- SQLite

\- HTML

\- CSS

\- JavaScript
